# by Qoncept

Сайт дизайнера и разработчика на Go, HTML templates, CSS и JavaScript.

## Запуск

```powershell
go run .
```

Запускайте весь пакет командой `go run .`, а не один файл `go run .\main.go`: обработчики заявок и QR-статистики находятся в `feedback.go` и `qr_tracking.go` и должны компилироваться вместе с `main.go`.

По умолчанию: http://localhost:8089. Страницы: `/`, `/websites`, `/software`, `/business-design`, `/outdoor-advertising`, `/design`.
Если ранее задавали другой порт через `LISTEN_ADDR`, вернуть 8089 можно так:

```powershell
$env:LISTEN_ADDR = ':8089'
go run .
```

Для отдельного локального предпросмотра на другом порту:

```powershell
$env:LISTEN_ADDR = '127.0.0.1:8090'
go run .
```

Публичный адрес по умолчанию — `https://qoncept.by`, в том числе за обратным прокси с внутренним Host localhost. Он используется для canonical, Open Graph, JSON-LD, sitemap и адресов QR. Другой публичный домен можно задать верхнеуровневым `siteUrl` в settings.json или переменной `SITE_URL` (имеет приоритет): только протокол и домен без пути. Для ссылок на localhost в отдельном предпросмотре задайте `LOCAL_PREVIEW=1`, привязку `127.0.0.1:8089` и оставьте оба параметра публичного адреса пустыми.

## Языки

Русский доступен по основным адресам всех шести страниц. Английская версия использует префикс `/en/`, украинская — `/uk/`, белорусская — `/be/`. Переводы страниц, форм, сообщений, интерактивных примеров, 404 и QR-кабинета находятся в `locales/messages.json`; они встроены в Go-приложение. После изменения переводов перезапустите сервер.

На первом посещении язык определяется по региону браузера из `Accept-Language` с учётом приоритетов. Для Минска, Киева и Москвы дополнительно используется локальная подсказка часового пояса: например, английский интерфейс браузера с поясом Europe/Minsk всё равно получает русский. Подсказка хранится в cookie `qoncept_region` одни сутки. Проверка выполняется до отображения страницы при автоматическом входе и не меняет язык явных ссылок. Для региона BY используется русский, для UA — украинский, для RU — русский, для остальных регионов — английский. Без региона учитывается язык браузера; без подходящих данных используется русский. Белорусский можно выбрать вручную. Внешние GeoIP-сервисы и запрос разрешения на геолокацию не используются.

Если в настройках включён `trustedProxyHeaders`, приложение также принимает `CF-IPCountry` или `X-Country-Code` от доверенного loopback-прокси. Прокси должен сам задавать эти заголовки, заменяя полученные от клиента: тогда страна имеет приоритет перед настройкой региона браузера. По умолчанию такие заголовки игнорируются.

В футере есть четыре языка и «Авто». Ручной выбор хранится в cookie `qoncept_language` на год и имеет приоритет перед автоматическим определением. «Авто» удаляет предпочтение и прежнюю подсказку региона, чтобы определить язык заново. Явная языковая ссылка, например `/be/design`, всегда открывается на указанном языке, поэтому ей можно поделиться. Внутренние ссылки сохраняют язык, QR-метки сохраняются при автоматическом перенаправлении. У каждой версии свои `lang`, `Content-Language`, canonical, Open Graph, JSON-LD и `hreflang`; sitemap содержит 24 страницы с взаимными языковыми ссылками и x-default.

## Контент и медиа

- `main.go`: проекты, подписи обложек, метаданные и структурированная разметка.
- `seo.go`: отдельные страницы разработки ПО, бизнес-дизайна и дизайна наружной рекламы.
- `docs/seo-research-2026-10-22.md`: поисковые кластеры, обоснование и источники.
- `templates/partials.html`: кейсы, услуги, условия работы, FAQ и контакты.
- `templates/media.html`: наружная реклама и анимации.
- `static/images/covers`: оригиналы обложек для полноразмерного просмотра.
- `static/images/responsive`: WebP 480/720/1200 для карточек; браузер выбирает один подходящий размер через srcset. Четыре обложки главной в 480 px занимают 105 КБ вместо 821 КБ оригиналов, все восемь — 199 КБ вместо 1,53 МБ. Hero-бюст — 11 КБ вместо 102 КБ. Фото наружки также адаптированы без увеличения исходного разрешения.
- `static/images/real`: фотографии наружной рекламы.
- `static/images/posters`: постеры для видео.
- `static/videos/real` и `static/videos/animations`: исходные ролики.
- `static/videos/previews`: облегчённые H.264 MP4 без аудиодорожки, с faststart.

Видео оформлены как беззвучные зацикленные анимации без элементов управления. Четыре облегчённых превью весят суммарно 2,27 МБ вместо 8,94 МБ исходных роликов; отдельный hero — 272 КБ. Источники подключаются только при приближении блока к экрану, видео играет лишь в видимой области и активной вкладке. При prefers-reduced-motion или экономии трафика показывается постер. На iOS заданы muted и playsinline, play() повторяется при обычном касании, возвращении во вкладку и появлении блока. Если политика устройства запрещает autoplay, остаётся аккуратная обложка без системного Play. Принудительно отменить такой запрет сайта нельзя. См. [WebKit](https://webkit.org/blog/6784/new-video-policies-for-ios/).

WorkService остаётся примером сервиса под задачи бизнеса. Внешняя ссылка на рабочую систему удалена, кнопка предлагает обсудить собственный сервис. Карточка содержит демонстрацию структуры без внутренних данных компании.

## Поведение

Тема автоматически следует настройкам устройства. Переключателя нет, прежние ручные настройки из localStorage не применяются.

Мобильная шапка: при прокрутке вниз скрывается строка навигации, бренд и кнопка связи остаются. Прокрутка вверх, нажатие на шапку или кнопку меню возвращают навигацию. Меню раскрывается поверх страницы без изменения высоты шапки; после нажатия игнорируются события восстановления прокрутки. Стрелки нарисованы inline SVG вместо символов, которые iOS может отобразить как эмодзи. Учтён `prefers-reduced-motion`.

SEO: уникальные title/description, canonical, Open Graph, Twitter Cards, JSON-LD Organization/WebSite/WebPage/Service/BreadcrumbList, `/robots.txt` и `/sitemap.xml`. Для разных намерений есть отдельные содержательные страницы с внутренними ссылками; в приоритете Беларусь, также указана удалённая работа с другими странами. Текст не обещает изготовление и монтаж наружной рекламы: предлагаются дизайн и подготовка файлов. Нет вымышленных адресов, рейтингов или цен. CSS/JS версионируются для кеширования; текстовые HTTP-ответы сжимаются gzip, диапазонные запросы видео сохраняются. Разметка не заменяет регистрацию публичного домена в инструментах поисковиков.

## Заявки и Telegram

Кнопки обсуждения проекта открывают форму. Клиент оставляет имя, Telegram/телефон/email, тип задачи и необязательное описание. «Мои контакты» раскрывает прямые способы связи.

Скопируйте `settings.example.json` в `settings.json` (локальный файл уже создан). Заполните:

- `telegram.botToken`: токен вашего Telegram-бота.
- `telegram.chatIds`: массив строк с ID чатов, например `["123456789"]`. Получатель должен начать диалог с ботом или добавить его в нужную группу.
- `qr.adminPassword`: пароль владельца для кабинета QR на публичном сайте. Логин не нужен: вход через страницу `/site/qr/login` с одним паролем.
- `qr.statsPath`: файл счётчиков, по умолчанию `data/qr_stats.json`.

После изменения настроек перезапустите сервер. `settings.json` и `data/` исключены из Git и не раздаются HTTP-сервером. Переменные окружения `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_IDS` (через запятую), `QR_ADMIN_PASSWORD`, `QR_STATS_PATH` переопределяют JSON. Путь к альтернативному файлу задаётся через `SETTINGS_FILE`.

`POST /api/contact` отправляет данные сервером через Telegram Bot API. Токен и список получателей не попадают в браузер. Успех возвращается только после подтверждения доставки хотя бы в один настроенный чат; при ошибке контакты остаются в форме. Персональные данные заявок не сохраняются в QR-статистике и не пишутся в лог приложения. Есть проверка полей, ограничение размера, honeypot и лимит попыток.

## Примеры проектов

Превью АВАЮССТРОЙ и WorkService работают прямо внутри карточек на главной и странице сайтов. Меню переключает локальные демонстрационные экраны без перехода на сторонние сервисы. ## QR-коды и источники

- `/qr?campaign=vizitka` — постоянный адрес для QR-кода. Считает переход и перенаправляет на сохранённый адрес кампании, включая другие сайты. Старые коды без назначения по-прежнему ведут на главную с UTM-метками.
- `/site/qr` — кабинет владельца: создание и редактирование кампаний, генератор PNG 768 × 768, счётчики, назначения и последние 30 дней с переходами. Выберите метку, введите полный HTTP(S)-адрес и нажмите «Сохранить ссылку». При редактировании того же назначения QR-код и счётчики сохраняются.
- `/site/qr/save` — изменение назначения только через POST владельца с CSRF-защитой. Публичный редирект не принимает произвольное назначение из query-параметров.
- `/site/qr/code.png?campaign=vizitka&download=1` — скачивание QR-кода с защитой доступа кабинета.

У разных носителей должны быть разные метки: `vizitka`, `banner`, `poster`. Метки сохраняются при переходах по страницам в пределах вкладки и передаются в Telegram вместе с заявкой. «Заявки с QR» считаются после подтверждённой отправки формы этого сайта. Заявки на внешних сайтах автоматически не отслеживаются. UTM-метки включаются отдельно для кампании; без них внешние параметры и fragment сохраняются без перекодирования, что важно для подписанных ссылок. Публичный редирект отдаёт 302 и no-store, поэтому обновлённое назначение не застревает в кеше. Статистика считает переходы, а не уникальных людей; время — Минск.

Для печатных материалов проверьте, что адрес внутри QR начинается с `https://qoncept.by/qr`. Если меняете домен сервиса, задайте `SITE_URL` или `siteUrl` до печати. Назначение можно менять без перепечатки, пока прежний домен и `/qr` доступны. QR, созданный с localhost, не годится для публичной печати. Храните `data/qr_stats.json` на постоянном диске и сохраняйте при обновлениях приложения.

Кабинет использует страницу входа с одним паролем `qr.adminPassword`, без браузерного окна Basic Auth. Сессия действует 8 часов, завершается кнопкой «Выйти» и сбрасывается при перезапуске сервера. Без настроенного пароля публичный доступ закрыт. Для локального предпросмотра без входа:

```powershell
$env:LISTEN_ADDR = '127.0.0.1:8090'
$env:LOCAL_PREVIEW = '1'
go run .
```

Локальное исключение работает только при привязке сервера к loopback, отсутствии `SITE_URL` и `siteUrl` и loopback-подключении. В публичном развёртывании `LOCAL_PREVIEW` не задавайте. Кабинет исключён из индексации и sitemap.

Интеграционные тесты используют тестовый Telegram API и временный файл статистики: реальные сообщения при `go test ./...` не отправляются.

Если сайт работает за локальным Nginx/Caddy, который переписывает `X-Real-IP`/`X-Forwarded-For`, можно добавить в `settings.json` верхнеуровневое `"trustedProxyHeaders": true`. Это разделяет лимиты формы по посетителям вместо общего адреса прокси. По умолчанию заголовки не доверенные; даже при включении они учитываются только для loopback-подключения и не влияют на доступ к кабинету.

## Текстовые эффекты и 404

Название в шапке меняется между by Qoncept и qoncept.by каждые 5 секунд, буквы поднимаются по очереди. Строка в хиро печатает направления работы. У неизвестных страниц — собственная страница 404 с настоящим HTTP-статусом 404 и noindex. При prefers-reduced-motion эффекты отключаются.

Эффекты адаптированы для HTML/CSS/JS по примерам Animata: [Bottom-Up Letters](https://animata.design/docs/text/bottom-up-letters), [Typing Text](https://animata.design/docs/text/typing-text), [Glitch Text](https://animata.design/docs/text/glitch-text). Реализация находится в static/motion.js и static/enhancements.css.

Для связи через Telegram клиент может оставить @username, ссылку t.me или номер телефона с кодом страны. Номер сохраняется в заявке как номер, без добавления @.
