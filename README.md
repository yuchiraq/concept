# by Qoncept

Сайт дизайнера и разработчика на Go, HTML templates, CSS и JavaScript.

## Запуск

```powershell
go run .
```

Запускайте весь пакет командой `go run .`, а не один файл `go run .\main.go`: обработчики заявок и QR-статистики находятся в `feedback.go` и `qr_tracking.go` и должны компилироваться вместе с `main.go`.

По умолчанию: http://localhost:8089. Страницы: `/`, `/websites`, `/design`.
Если ранее задавали другой порт через `LISTEN_ADDR`, вернуть 8089 можно так:

```powershell
$env:LISTEN_ADDR = ':8089'
go run .
```

Для отдельного локального предпросмотра на другом порту:

```powershell
$env:LISTEN_ADDR = '127.0.0.1:8090'
go run .
```

На публичном сервере задайте `SITE_URL` с реальным адресом сайта (протокол и домен без пути). Он используется в canonical, Open Graph, JSON-LD и sitemap. Если сайт работает за HTTPS-прокси, это обеспечивает правильный публичный протокол в ссылках. Без переменной адрес формируется из текущего HTTP-запроса.

## Контент и медиа

- `main.go`: проекты, подписи обложек, метаданные и структурированная разметка.
- `templates/partials.html`: кейсы, услуги, условия работы, FAQ и контакты.
- `templates/media.html`: наружная реклама и анимации.
- `static/images/covers`: актуальные обложки, используются напрямую.
- `static/images/real`: фотографии наружной рекламы.
- `static/images/posters`: постеры для видео.
- `static/videos/real` и `static/videos/animations`: исходные ролики.

Видео оформлены как беззвучные зацикленные анимации без элементов управления. В хиро OGBIGTOY показан видеороликом в квадратной рамке обложки. За пределами экрана, в фоновой вкладке и при prefers-reduced-motion воспроизведение приостанавливается; до загрузки виден постер.

WorkService остаётся примером сервиса под задачи бизнеса. Внешняя ссылка на рабочую систему удалена, кнопка предлагает обсудить собственный сервис. Карточка содержит демонстрацию структуры без внутренних данных компании.

## Поведение

Тема автоматически следует настройкам устройства. Переключателя нет, прежние ручные настройки из localStorage не применяются.

Мобильная шапка: при прокрутке вниз скрывается строка навигации, бренд и кнопка связи остаются. Прокрутка вверх, нажатие на шапку или кнопку меню возвращают навигацию. Меню раскрывается поверх страницы без изменения высоты шапки; после нажатия игнорируются события восстановления прокрутки. Стрелки нарисованы inline SVG вместо символов, которые iOS может отобразить как эмодзи. Учтён `prefers-reduced-motion`.

SEO: уникальные title/description, canonical, Open Graph, Twitter Cards, JSON-LD с услугами, `/robots.txt` и `/sitemap.xml`. Разметка не заменяет регистрацию публичного домена в инструментах поисковиков.

## Заявки и Telegram

Кнопки обсуждения проекта открывают форму. Клиент оставляет имя, Telegram/телефон/email, тип задачи и необязательное описание. «Мои контакты» раскрывает прямые способы связи.

Скопируйте `settings.example.json` в `settings.json` (локальный файл уже создан). Заполните:

- `telegram.botToken`: токен вашего Telegram-бота.
- `telegram.chatIds`: массив строк с ID чатов, например `["123456789"]`. Получатель должен начать диалог с ботом или добавить его в нужную группу.
- `qr.adminPassword`: пароль владельца для кабинета QR на публичном сайте. Логин: `owner`.
- `qr.statsPath`: файл счётчиков, по умолчанию `data/qr_stats.json`.

После изменения настроек перезапустите сервер. `settings.json` и `data/` исключены из Git и не раздаются HTTP-сервером. Переменные окружения `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_IDS` (через запятую), `QR_ADMIN_PASSWORD`, `QR_STATS_PATH` переопределяют JSON. Путь к альтернативному файлу задаётся через `SETTINGS_FILE`.

`POST /api/contact` отправляет данные сервером через Telegram Bot API. Токен и список получателей не попадают в браузер. Успех возвращается только после подтверждения доставки хотя бы в один настроенный чат; при ошибке контакты остаются в форме. Персональные данные заявок не сохраняются в QR-статистике и не пишутся в лог приложения. Есть проверка полей, ограничение размера, honeypot и лимит попыток.

## Примеры проектов

Превью АВАЮССТРОЙ и WorkService работают прямо внутри карточек на главной и странице сайтов. Меню переключает локальные демонстрационные экраны без перехода на сторонние сервисы. У WorkService компьютерная и мобильная версии синхронно показывают выбранный раздел: обзор, задачи, учёт топлива или инвентарь. Все записи и количества в превью демонстрационные; действия в нём не меняют данные реального сервиса.

## QR-коды и источники

- `/qr?campaign=vizitka` — публичный адрес для QR-кода. Считает переход и ведёт на главную с `utm_source=qr`, `utm_medium=offline`, `utm_campaign=vizitka`.
- `/site/qr` — кабинет владельца: генератор PNG 768 × 768, счётчики, кампании и последние 30 дней с переходами.
- `/site/qr/code.png?campaign=vizitka&download=1` — скачивание QR-кода с защитой доступа кабинета.

У разных носителей должны быть разные метки: `vizitka`, `banner`, `poster`. Метки сохраняются при переходах по страницам в пределах вкладки и передаются в Telegram вместе с заявкой. «Заявки с QR» считаются после подтверждённой отправки. Статистика считает переходы, а не уникальных людей; время — Минск.

Для печатных материалов задайте `SITE_URL` с вашим публичным HTTPS-доменом. QR, созданный с localhost, не годится для публичной печати. Храните `data/qr_stats.json` на постоянном диске и сохраняйте при обновлениях приложения.

На публичном сервере кабинет требует логин `owner` и пароль `qr.adminPassword`; без пароля доступ закрыт. Для локального предпросмотра без входа:

```powershell
$env:LISTEN_ADDR = '127.0.0.1:8090'
$env:LOCAL_PREVIEW = '1'
go run .
```

Локальное исключение работает только при привязке сервера к loopback, отсутствии `SITE_URL` и loopback-подключении. В публичном развёртывании `LOCAL_PREVIEW` не задавайте. Кабинет исключён из индексации и sitemap.

Интеграционные тесты используют тестовый Telegram API и временный файл статистики: реальные сообщения при `go test ./...` не отправляются.

Если сайт работает за локальным Nginx/Caddy, который переписывает `X-Real-IP`/`X-Forwarded-For`, можно добавить в `settings.json` верхнеуровневое `"trustedProxyHeaders": true`. Это разделяет лимиты формы по посетителям вместо общего адреса прокси. По умолчанию заголовки не доверенные; даже при включении они учитываются только для loopback-подключения и не влияют на доступ к кабинету.
