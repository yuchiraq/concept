# Яндекс Метрика

Счётчик **113798986** подключён через `static/analytics.js` и `templates/base.html`.
Он загружается только на HTTPS-доменах `qoncept.by` и `www.qoncept.by`, на шести публичных страницах и их языковых версиях. На localhost, других доменах, нестандартных портах, неизвестных URL, в QR-кабинете и API запросов к Метрике нет. `Global Privacy Control` и `Do Not Track` учитываются. Для отдельной технической проверки можно до загрузки скрипта задать `window.qonceptDisableAnalytics = true`.

В кабинете Метрики создайте цели типа **«JavaScript-событие»** с точными идентификаторами:

| Идентификатор | Когда отправляется |
| --- | --- |
| `lead_form_open` | Форма действительно открылась |
| `lead_submit_success` | API вернул успешный HTTP-ответ и `success: true` |
| `contact_telegram` | Клик по публичному Telegram владельца |
| `contact_email` | Клик по публичной почте владельца |
| `contact_instagram` | Клик по Instagram владельца |

Оставьте выключенными **Вебвизор, аналитику форм, автоматические цели, автосбор Ecommerce и Advanced Matching** в настройках счётчика. В коде выключены Webvisor, карта кликов, автосбор внешних ссылок, отслеживание хеша, Ecommerce и Яндекс Тег Менеджер. Поэтому аналитика сайта использует только перечисленные явные цели. Не включайте запись полей и дополнительные инструменты сбора без отдельной проверки.

Скрипт не читает имя, контакт, сообщение и другие значения полей; не отправляет их в Метрику. В `reachGoal` передаётся только фиксированный идентификатор, без параметров. Просмотры передаются вручную: адрес без query/fragment, фиксированный заголовок `by Qoncept`, у источника перехода только origin. Автоматический просмотр при инициализации отключён через `defer: true`. Политика `strict-origin-when-cross-origin` также ограничивает HTTP Referer внешних запросов адресом origin. Метрика как внешний сервис продолжает собирать обычные технические сведения о браузере, устройстве и посещении.

Проверки без боевых запросов:

```powershell
node --test tests/analytics.test.cjs
node --check static/analytics.js
```

Тесты используют изолированный JavaScript-контекст и заглушки, не загружают `tag.js`, не отправляют заявки и события. Не проверяйте цели отправкой вымышленных заявок на работающий сайт. Если счётчик заблокирован браузером, форма и прямые ссылки продолжают работать.

Официальные методы: [инициализация](https://yandex.ru/support/metrica/ru/code/counter-initialize), [hit](https://yandex.ru/support/metrica/ru/objects/hit), [reachGoal](https://yandex.ru/support/metrica/ru/objects/reachgoal). Поведение очищенного URL для целей дополнительно проверено по [официальному исходному коду](https://github.com/yandex/metrica-tag/blob/main/src/providers/goal/goal.ts).
